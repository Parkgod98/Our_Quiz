# Product Spec

## 사용자

초기 사용자는 같은 기술 스터디를 진행하는 2명입니다. 이후 다른 소규모 스터디에도 확장할 수 있는 구조를 유지합니다.

## 해결하려는 문제

- AI에게 문제를 만들어 달라고 할 때마다 결과 형식이 달라 누적 관리하기 어렵습니다.
- 같은 문제집을 풀어도 누구에게 어떤 문제가 어려웠는지 기록이 흩어집니다.
- 문제를 보강하면 기존 문제집의 점수 기준이 달라질 수 있습니다.
- 오답을 다시 찾아 반복 학습하기 어렵습니다.

## MVP 사용자 흐름

### 회원가입 / 로그인

1. 사용자가 이메일과 비밀번호를 입력합니다.
2. 회원가입하면 별도 이메일 확인 없이 즉시 세션을 발급합니다.
3. 바로 홈과 스터디 기능을 사용할 수 있습니다.

이메일 인증 메일, 확인 링크, 가입 승인 절차는 MVP에서 사용하지 않습니다.

### 문제 등록

1. AI에게 범위와 문제 수를 요청합니다.
2. `Our Quiz Question Set v1` JSON 파일을 받습니다.
3. 사이트에서 문제집으로 추가합니다.
4. Validator가 형식과 정답 구조를 검사합니다.
5. 저장 후 내부적으로 불변 Version을 Publish합니다.
6. 스터디에 해당 Version을 배정합니다.

### 문제 풀이

1. 사용자가 문제집의 `풀기` 또는 `이어 풀기`를 누릅니다.
2. 새 Attempt가 생성되거나 진행 중 Attempt를 이어서 사용합니다.
3. 답안과 다시 볼 문제 상태는 풀이 중 자동 저장됩니다.
4. 제출하면 서버가 최종 채점합니다.
5. 점수, 답안, Topic별 오답을 저장하고 결과 화면에서 확인합니다.

### 복습

- 틀린 문제만 보기
- 반복 오답 보기
- 과거 Attempt 점수 변화 보기
- Topic별 정확도 보기
- 오답만 다시 풀고 서버에서 재채점하기

## 사용자 화면의 언어 원칙

내부 도메인과 사용자 언어를 분리합니다.

- 코드와 DB에서는 `Question Set`, `Version`, `Attempt`, `Topic` 같은 정확한 도메인 용어를 유지합니다.
- 일반 사용자 화면에서는 `문제집`, `버전`, `풀이 기록`, `주제`처럼 자연스러운 한국어를 우선합니다.
- `Snapshot`, `Start`, `Attempt`, `Validation`, `Supabase` 같은 구현 용어를 일반 안내 문구에 노출하지 않습니다.
- 오류는 원본 SDK/DB 메시지를 그대로 보여주지 않고 사용자가 다음 행동을 알 수 있는 문장으로 변환합니다.
- JSON, 버전, 내보내기처럼 실제 기능 이해에 필요한 기술 용어는 문제집 관리의 고급 기능에서만 사용합니다.

## 정보 구조

로그인 후 주 메뉴는 다음 네 가지로 유지합니다.

- 홈: 이어 풀기, 학습 요약, 최근 기록, 취약 주제
- 스터디: 참여 중인 여러 스터디, 멤버, 공유 문제, 그룹 기록, 설정
- 문제집: 내가 추가한 문제집과 버전 관리
- 오답노트: 오답과 반복 오답 복습

`Import`, `Demo` 같은 개발·보조 기능은 주 내비게이션에 직접 노출하지 않습니다.

## MVP 필수 기능

- Email/Password 회원가입 및 로그인
- 회원가입 직후 즉시 로그인(Email Confirmation 없음)
- 여러 Study Group 참여/관리
- Question Set + Version
- JSON Import / Validation / Export
- 5개 Question Type
- Quiz Player
- Start 시 Attempt 생성, 자동 저장, 이어 풀기
- 결과 화면과 오답 확인
- 오답노트와 반복 오답 재풀이
- 개인 점수 History
- 그룹의 동일 Version 공유

## 비목표

초기에는 아래를 하지 않습니다.

- 이메일 인증 / 가입 승인
- 사이트 내부 AI 문제 자동 생성
- 실시간 대전
- 복잡한 랭킹/게임화
- 공개 문제 마켓
- 관리자용 CMS
- 결제

## 성공 기준

- Week1 100개 이상의 문제를 JSON 한 번으로 Import할 수 있습니다.
- 회원가입 후 별도 이메일 인증 없이 즉시 서비스를 사용할 수 있습니다.
- 사용자가 여러 스터디에 참여하고 각 스터디를 독립적으로 관리할 수 있습니다.
- 두 사용자가 같은 Version으로 시험을 시작할 수 있습니다.
- 긴 문제집을 중간에 나가도 저장된 위치와 답안으로 이어서 풀 수 있습니다.
- 문제 추가 후 새 Version을 만들어도 이전 점수는 변하지 않습니다.
- 사용자가 자신이 자주 틀리는 Topic을 확인하고 오답만 다시 풀 수 있습니다.
- Question Set을 다시 Export하여 AI에게 보강 요청할 수 있습니다.
