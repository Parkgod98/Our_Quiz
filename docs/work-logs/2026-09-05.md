## 17:05 — Supabase SSR 타입 오류 수정

### 작업한 내용
- `proxy.ts`의 cookie `setAll`이 `NextResponse`를 반환하지 않고 closure의 response만 갱신하도록 수정함.
- Server Client의 사용하지 않는 headers parameter를 제거함.
- Next build가 자동 제안한 `.next/dev/types/**/*.ts` include를 `tsconfig.json`에 반영함.

### 이유
- 설치된 최신 `@supabase/ssr`의 `SetAllCookies` 타입은 `void | Promise<void>` 반환을 요구함.
