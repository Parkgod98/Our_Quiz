## 00:19 — 스터디 기록 공유와 학습 결과 가독성 개선

### 작업한 내용
- 운영자가 아닌 스터디 멤버도 같은 그룹의 전체 풀이 기록 요약을 볼 수 있도록 `get_group_detail_overview`를 보강함.
- 그룹 기록에는 문제집별 점수, 전체 문제 수, 정답 수, 오답 수를 포함하고, 본인 제출 기록만 결과 상세 링크를 제공함.
- 다른 멤버의 개별 제출 답안과 정답 상세는 계속 노출하지 않음.
- 학습 결과 화면에서 오답이 있으면 `오답만` 필터를 기본으로 선택하고 `전체`와 즉시 전환할 수 있게 함.
- 단일/복수 선택 문제의 결과를 선지 단위로 비교해 정답 선지는 초록색, 잘못 선택한 선지는 빨간색으로 표시함.
- 복수 선택 결과에서 순서를 의미하지 않는 화살표 표기를 제거하고 선지별 `내 답 · 정답`, `정답`, `내 답 · 오답` 상태를 표시함.
- 순서 맞추기 유형에서만 실제 순서를 표현하기 위해 화살표 표기를 유지함.
- `get_attempt_result` 결과에 문제 유형을 포함해 결과 UI가 문제 유형에 맞는 표현을 선택할 수 있게 함.
- 일반 멤버가 운영자의 제출 요약까지 확인할 수 있고, 본인 결과 payload에는 문제 유형이 포함되는지 E2E를 보강함.

### 이유
- 기존 운영 배포에서는 일반 멤버가 기록 탭에서 그룹 전체 기록을 안정적으로 확인하지 못했고, 운영자와 일반 멤버의 기록 가시성이 달랐음.
- 결과 화면이 모든 문항을 길게 나열해 오답 몇 개를 찾기 위해 긴 스크롤이 필요했음.
- 복수 선택 문제는 배열을 공통 포맷으로 렌더링하면서 `→`로 연결해 실제 순서가 있는 것처럼 보였고, 내 선택과 정답의 차이를 한눈에 확인하기 어려웠음.
