# 2026-10-11 작업 로그

## 01:14 — 스터디 멤버 문제집 공유 UX와 권한 확장

### 작업한 내용
- 문제집 상세의 '스터디에 추가하기' 버튼이 스터디 목록으로 이동만 하던 문제를 수정하고, 참여 스터디 선택 후 실제 문제집 공유 요청을 전송하게 함.
- 문제집 상세에서는 최신 버전을 대상으로 공유할 스터디를 선택하고 이미 공유한 스터디는 제외함.
- 스터디 운영자 외 일반 멤버도 본인 문제집을 추가할 수 있게 공유 패널을 노출함.
- 그룹 상세 RPC는 운영자와 일반 멤버 모두에게 본인 소유·미배정 버전만 반환하도록 새 migration에서 갱신함.
- group_question_sets INSERT RLS는 참여 멤버십, 본인 소유 문제집, assigned_by 본인 일치를 모두 확인함.
- 중복 공유/권한 부족/미존재/네트워크 실패 안내를 구분하고 공유 API 실패 원본은 서버 로그에 남김.
- Core E2E에 일반 멤버의 본인 문제집 공유 성공, 타인 소유 문제집 공유 차단, 비멤버 공유 차단, 배정 목록 갱신 검증을 추가함.

### 이유
- 문제집 상세의 버튼 문구와 실제 이동 동작이 달라 이용자가 공유됐다고 오해할 수 있었음.
- 일반 멤버는 공유 UI도 없고 INSERT RLS도 운영자에게만 허용돼 스터디 공동 문제집 운영이 불가능했음.
- 다른 사람의 비공개 문제집을 공유 후보로 노출하지 않고 서버 권한까지 일치시킬 필요가 있음.
